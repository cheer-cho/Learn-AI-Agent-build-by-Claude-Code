# Course Map

One continuous project — the **TechCorp Knowledge Agent** — built across 23
modules in 5 levels. Interactive version with checkpoints: [ROADMAP.html](ROADMAP.html).

## Level 1 — Foundations (Modules 00–04)

| Module | You build | Key ideas |
|---|---|---|
| [00 Setup](course/00_setup/README.md) | A verified working environment | venvs, env vars, API keys, offline mode |
| [01 LLM Fundamentals](course/01_llm_fundamentals/README.md) | Token-and-context explorer | tokens, context windows, noise vs signal |
| [02 First API Call](course/02_first_api_call/README.md) | Raw SDK chat client with cost math | roles, response anatomy, usage, errors |
| [03 LangChain](course/03_langchain/README.md) | Same call via framework + structured output | abstraction trade-offs, templates, parsers |
| [04 Prompt Engineering](course/04_prompt_engineering/README.md) | Rubric-scored prompt comparisons | specificity, shots, decomposition |

**Career milestone:** call and control an LLM professionally — the baseline of every AI job posting.

## Level 2 — Retrieval & RAG (Modules 05–09)

| Module | You build | Key ideas |
|---|---|---|
| [05 Embeddings](course/05_embeddings/README.md) | Similarity explorer | vectors, cosine, semantic vs keyword |
| [06 Semantic Search](course/06_semantic_search/README.md) | Search engine over TechCorp docs | top-k, thresholds, precision/recall |
| [07 Vector DB & Chunking](course/07_vector_database/README.md) | Persistent index + chunking experiment | ChromaDB, chunk size trade-offs |
| [08 RAG](course/08_rag/README.md) | Grounded Q&A with citations + abstention | retrieval → augmentation → generation |
| [09 Grounding & Evaluation](course/09_grounding_and_evaluation/README.md) | Evaluation harness + report | hit rate, source accuracy, abstention correctness |

**Career milestone:** build a trustworthy knowledge system — the most common production AI workload.
