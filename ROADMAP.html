How every module works

Same structure everywhere, so you never guess where things are. Offline-first: default tests run without paid API calls; live-model labs are clearly marked.

  • concepts.md — the why, plain language, no unexplained jargon
  • lab.md — step-by-step tasks with checkpoints and hints
  • starter/ — runnable code with meaningful TODOs
  • solution/ — working reference implementation
  • tests/ — automated verification of what you built
  • checklist.md — self-check before moving on

What you walk away with

A production agent system

Multi-agent, memory-backed, streaming, guarded, deployed — running on your machine, rebuildable from a clean clone.

Evidence, not vibes

Evaluation reports proving retrieval quality, answer grounding, and that each upgrade actually helped.

A portfolio piece

Architecture doc with trade-off reasoning, a five-minute demo script, and a publishable project README.

Interview readiness

A question bank mapping every module to common AI-engineering interview topics — answered by code you wrote.

How to use this page

This is your home base. Click a module title to jump into its lab; when its checklist.md passes, come back and tick it off. Checkpoints save in this browser via localStorage — no server, no account.
